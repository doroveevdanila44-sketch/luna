# CLAUDE.md — правила работы в проекте «Луна»

## Что это
Сайт фитнес-клуба «Луна», Петропавловск-Камчатский. MVP: одна главная страница
по макету + маршруты-заглушки под будущее расширение.

## Стек
Next.js 14 App Router, TypeScript (strict), Tailwind CSS, next/font, next/image.
Деплой Vercel. Node 20.

## Железные правила
1. **Макет — источник правды.** Композиция, порядок блоков и пропорции — как в
   `~/Desktop/Луна/Макет.png`. Отступы и типографику берём из docs/DESIGN.md.
2. **Никакого текста в JSX.** Всё — из `/data`. Меняется контент → правится один файл.
3. **Никаких выдуманных данных.** Телефон, адрес, часы, цены — только из
   docs/CONTENT.md. Если данных нет — заглушка с пометкой `TODO`, не фантазия.
4. **Оригинальные пропорции фотографий.** Не растягивать. Кроп — только через
   `object-cover` с осмысленным `object-position`.
5. **Адаптив обязателен** на четырёх контрольных ширинах: 1440, 1024, 768 (iPad
   вертикально), 390 (iPhone). Проверяй каждую секцию на всех четырёх.
6. **Доступность:** видимый фокус на всех интерактивных элементах, контраст текста
   к фону не ниже 4.5:1, `prefers-reduced-motion` уважается.
7. **Главная не должна становиться бесконечной.** На узких экранах количество
   карточек в секции сокращается, а не превращается в километровую колонку.
   Правило для всех сеточных секций (направления, атмосфера, тренеры, отзывы):
   массив данных общий, компонент показывает срез через `.slice()` по брейкпоинту,
   остальное уходит за ссылку «СМОТРЕТЬ ВСЕ →». Скрывать лишнее через
   `display:none` нельзя — карточки всё равно грузятся.
   Длинные тексты режутся по строкам (`line-clamp`), не по символам.
8. После каждого этапа — `git add -A && git commit && git push`.

## Чего НЕ делать
- Не подключать UI-киты (shadcn, MUI, Chakra) — Tailwind и свои компоненты.
- Не ставить библиотеки анимаций тяжелее нужного: только CSS + IntersectionObserver.
  Если очень нужно — `framer-motion`, но сначала спроси.
- Не менять порядок секций «на своё усмотрение».
- Не трогать содержимое `/public/images` после копирования ассетов.
- Не добавлять cookie-баннеры, чаты, аналитику — их подключим отдельно.
