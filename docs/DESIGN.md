# Дизайн-система

## Цвета (CSS-переменные в globals.css, экспортом в tailwind.config)
--bg        #0B0C0A   основной фон
--panel     #131513   плашки, карточки
--panel-2   #0E100D   вложенные карточки
--line      #26291F   границы, разделители
--green     #B6E82A   акцент: кнопки, подчёркивания, цифры
--green-dim #8FBE1E   hover акцента
--text      #EDEFE9   основной текст
--muted     #8E938A   вторичный текст, подписи

Зелёный — только акцент. Никаких зелёных заливок больше кнопки.
Крупные площади всегда чёрные, фотографии дают весь цвет.

## Шрифты (next/font/google, subsets: ['cyrillic','latin'])
- **Unbounded** — заголовки, логотип, цены, названия секций и карточек.
  Веса 600/700/800. Всегда UPPERCASE у h1/h2, letter-spacing -0.015em у крупного,
  +0.10em у логотипа.
- **Onest** — весь остальной текст, навигация, кнопки, подписи. Веса 400/500/600.

Unbounded широкий — в заголовках максимум 2–3 слова в строку, иначе ломается ритм.
h1 ограничить `max-width: 12ch` на десктопе.

## Типографическая шкала
h1 (hero)      clamp(30px, 4.6vw, 52px) / 1.06 / Unbounded 700 / UPPERCASE
h2 (секция)    clamp(20px, 2.6vw, 28px) / 1.2  / Unbounded 700 / UPPERCASE / ls .06em
h3 (карточка)  14–16px / Unbounded 700 / UPPERCASE / ls .02em
lead           16px / 1.62 / Onest 400
body           15px / 1.6  / Onest 400
caption        13px / 1.55 / Onest 400 / --muted
eyebrow        12px / ls .3em / UPPERCASE / Onest 600 / --muted
button         13px / ls .14em / UPPERCASE / Onest 600
цена           30–34px / Unbounded 700

## Сетка и отступы
Контейнер max-width 1280px, паддинг 24px (мобайл 20px).
Вертикальный ритм секций: 96px десктоп / 64px планшет / 48px мобайл.
Радиусы: карточки 10px, крупные блоки 14px, кнопки 6px.

## Заголовок секции
Слева h2, справа от него горизонтальная зелёная линия (не более 170px),
в конце строки ссылка «СМОТРЕТЬ ВСЕ →» цветом --muted. Ровно как в макете.

## Анимации (сдержанно)
- Появление секций при скролле: opacity 0→1, translateY 16px→0, 500ms ease-out,
  через IntersectionObserver, срабатывает один раз.
- Всё оборачивается в `@media (prefers-reduced-motion: reduce)`.

## Система отклика — закон для всего сайта

**Реакция появляется при НАВЕДЕНИИ (мышь) и при КАСАНИИ (палец), до клика.**

```
Кнопка:                scale(1.05), нажатие 1.07
Карточка:              scale(1.04) + граница --green + свечение
Текст и иконка:        scale(1.08)
Фото внутри карточки:  scale(1.06)
Широкий баннер:        scale(1.012) — больше нельзя, вылезет за паддинг
transition:            250ms ease
```

Всё это живёт в globals.css готовыми классами, а не расписывается заново
в каждом компоненте:

| класс | что делает |
|---|---|
| `react` | общий transition на все реагирующие свойства |
| `grow-btn` / `grow-card` / `grow-wide` | рост кнопки / карточки / широкого блока |
| `grow-text` / `grow-photo` | рост текста и иконки / фотографии внутри `group` |
| `glow` | зелёное свечение наружу |
| `lit` / `lit-in-group` | зелёная граница со свечением |
| `lit-outline` / `fill-on-touch` | контурная кнопка / круглая стрелка тарифа |
| `nudge-x` / `nudge-x-back` | сдвиг стрелки в ссылке |
| `border-green-soft` | приглушённая зелёная граница в покое |

Каждый класс объявлен дважды: в `@media (hover: hover)` через `:hover`
и в `@media (hover: none)` через `:active`. На тач-экране эффект появляется,
пока палец на элементе, и снимается при отпускании. `touch-action` нигде
не переопределяется — листание страницы важнее анимации.

**Масштаб задаётся обычным `transform: scale()`, а не утилитами Tailwind.**
Это не стилистика, а защита: Tailwind масштабирует через переменные
`--tw-scale-*`, и одно правило, сбросившее их, молча убивает наведение на
всём сайте. Ровно это и случилось — сброс `--tw-scale-*` с `!important`
внутри `prefers-reduced-motion` три итерации подряд гасил hover у всех,
у кого в системе включено «Уменьшение движения». Собственный `transform`
переменной подменить нельзя.

`prefers-reduced-motion: reduce` обнуляет только длительности переходов
и анимацию появления. Состояния при этом остаются: отклик виден, просто
переключается мгновенно, без движения. Гасить сами состояния нельзя —
пользователь останется без обратной связи.

Зелёные кнопки заливку не меняют ни в одном состоянии: `--green` всегда.
Затемнение в `--green-dim` делало их грязными. Отклик — рост и свечение.

Исключения:
- **Атмосфера клуба** — единственная секция без отклика: фотографии стоят
  неподвижно. Анимация появления при скролле у неё остаётся.
- **Преимущества** — блоки на общем фоне, а не карточки. Растут только
  заголовок и иконка; фон, рамка и тень не появляются.

## Изображения
next/image, `sizes` прописан для каждой сетки, `priority` только у hero.
Hero и широкий баннер — плавный градиент от --bg сверху, стык фона и фото не должен
читаться линией (частая ошибка: градиент выглядит отдельной плашкой — это брак).
На мобиле у широких баннеров текст уходит вверх, фото обрезается со стороны без объекта.
