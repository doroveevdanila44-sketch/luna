# Контекст проекта

## Клиент
Фитнес-клуб «Луна» — новый клуб в Петропавловске-Камчатском. Рейтинг 4.9 на 2ГИС,
96 отзывов, 111 оценок. Карточка: https://2gis.ru/p_kamchatskiy/firm/70000001105373821
ИП Федоров Виталий Эдуардович.

## Позиционирование
Самый современный тренажёрный зал Северо-Востока. Не «фитнес для всех», а место с
характером: чёрный интерьер, шестиугольные светильники, подсвеченная луна на стене,
кислотно-зелёный неон, гантели и гири с фирменной гравировкой. Продаём атмосферу и
дисциплину, а не скидки.

## Аудитория
18–40 лет, город, самостоятельные тренировки + групповые программы. Заходят с
телефона. Главное действие — «купить абонемент» и «первое занятие бесплатно».

## Задача сайта на MVP
1. Показать, как выглядит клуб (фотографии — сильнейший актив, их много и они хорошие).
2. Дать цены и контакты без поиска.
3. Довести до звонка / Telegram.

## Куда сайт будет расти (закладываем архитектуру, не реализуем)
- Расписание групповых занятий (таблица по дням).
- Онлайн-покупка и продление абонемента, промокоды.
- Личный кабинет клиента, заморозка карты.
- Страницы тренеров с записью на персональную тренировку.
- Галерея и новости/акции.

## Ограничения MVP
- Фотографий тренеров нет — четыре карточки-заглушки.
- Из пяти фото «Атмосфера клуба» готовы три (1, 3, 4) — секция строится на трёх,
  сетка должна корректно принять пятую и вторую позже без переписывания.
- Логотипа нет — везде текстовое начертание «ЛУНА» + подпись «ФИТНЕС-КЛУБ».
